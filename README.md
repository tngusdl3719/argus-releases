# OfficeAwake

맥북 덮개를 닫아도 잠들지 않게 해 주는 메뉴바 앱이에요. 정해 둔 Wi-Fi에 연결돼 있고 근무 요일·시간일 때만 켜고,
조건이 끝나면 원래대로 되돌려요. 이 저장소는 배포용이에요. [Releases](../../releases)에서 DMG를 받으세요.

## 설치

1. 최신 릴리스에서 `OfficeAwake-<버전>.dmg`를 받아요.
2. DMG를 열고 `OfficeAwake.app`을 `Applications` 폴더로 끌어다 놓아요.
3. 처음 열 때는 Apple 공증을 받지 않은 앱이라 경고가 떠요.
   - macOS 14: Finder에서 앱을 우클릭 → "열기" → "열기".
   - macOS 15 이상: 한 번 열어 본 뒤 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기".
4. 처음 실행하면 관리자 비밀번호를 한 번 물어요(잠자기 설정을 바꿀 권한을 설치해요). 로컬 관리자 권한이 필요해요.
5. 위치 권한을 물어요. macOS는 Wi-Fi 이름을 읽을 때 위치 권한을 요구해요. 위치 정보는 저장하거나 보내지 않아요.
6. "백그라운드 항목 추가됨" 알림이 떠요. 로그인할 때와 비정상 종료 뒤에 앱을 다시 띄우는 항목이에요.

메뉴 막대 아이콘이 해면 켜짐, 달이면 꺼짐이에요. 조건은 메뉴 → 설정…에서 바꿔요.

## 자동 업데이트

앱이 하루에 한 번 이 저장소의 최신 릴리스를 확인해요. 새 버전이 있으면 받아서 서명을 확인하고, 맞을 때만 스스로 바꿔 끼운 뒤
다시 시작해요. 켜져 있는 동안에는 미뤘다가 꺼졌을 때 설치해요. 설정 → 업데이트에서 끌 수 있어요.

## 제거

메뉴 → "제거…" → 관리자 비밀번호를 입력한 뒤 `/Applications/OfficeAwake.app`을 휴지통으로 옮겨요.

## 알려진 제약

- Apple 개발자 인증서가 아닌 ad-hoc 서명이라, 새 버전으로 바뀔 때마다 위치 권한을 다시 물을 수 있어요.
  다시 허용할 때까지 상태 줄은 `꺼짐 · 위치 권한 없음`이에요.
- 켜져 있는 동안에는 자동 화면 잠금이 동작하지 않아요. 자리를 비울 때는 Control+Command+Q로 직접 잠가 주세요.
